## Interactive visualizations (Tables 9, 10, 12, 14, 15, 16, 17, 18)

This folder contains **standalone HTML embeds** (no build step). Charts read numeric summaries from `data/*.json`.

### Refresh charts from your ACS PUMS extract (`texasvets_eda.R`)

1. Set your IPUMS API key: `Sys.setenv(IPUMS_API_KEY = "…")` (do not commit the key).
2. In R, run `source("texasvets_eda.R")` through the step that builds `tx_survey` and exports JSON (the script sources `poster_viz/export_poster_viz_data.R` at the end).
3. Commit the updated `poster_viz/data/*.json` files and push to GitHub Pages.

Requirements: `jsonlite`, `survey`, `srvyr`, `rlang`, `ipumsr`, plus dependencies from `texasvets_eda.R`.

The **county map** (`map_county_veterans_2023.html`) uses the bundled `county_veterans_2023.csv`. It is **not** regenerated by `texasvets_eda.R` unless you add a PUMA→county allocation workflow.

### Files
- `table09.html`: Median age of Texas veterans by period of service
- `table10.html`: Disability types — veterans vs nonveterans (Texas, 18+)
- `table12.html`: Service-connected disability ratings (veterans)
- `table14.html`: Labor force by age — employed vs unemployed
- `table15.html`: Class of worker (veteran labor force)
- `table16.html`: Top 20 industries (employed veterans)
- `table17.html`: Top 20 occupations (employed veterans)
- `table18.html`: Average wage by education (employed veterans)
- `map_county_veterans_2023.html`: Interactive county choropleth (uses `county_veterans_2023.csv`)

### How to embed in a digital poster

- **Option A (recommended): iframe**
  - Upload the HTML files to any static host (GitHub Pages, Netlify, university web space, etc.)
  - Embed with an iframe, e.g.:

```html
<iframe
  src="table16.html"
  width="100%"
  height="520"
  style="border:0;"
  loading="lazy"
></iframe>
```

- **Option B: open directly**
  - Double-click an `.html` file to open locally (works best in Chrome).
